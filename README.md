# 🍷 Wine Quality Dashboard

An interactive **Streamlit dashboard** for analyzing and predicting wine quality using chemical properties and machine learning.

---

## 🚀 Features

* 📊 Interactive Wine Quality Analytics
* 🧪 Chemical Property Analysis
* ☢️ Acidity Intelligence Hub
* ⚠️ Sulfur & Chemical Insights
* 🤖 Random Forest Quality Prediction
* 📈 Advanced KPIs & Visualizations
* 🎨 Futuristic Dark-Themed UI
* 🔍 Global Dataset Filters
* ⚡ Real-Time Predictions
* 📂 CSV Dataset Upload Support

---

## 🖥️ Dashboard Pages

| Page                  | Description                                     |
| --------------------- | ----------------------------------------------- |
| 🍷 Dashboard          | Dataset overview, KPIs & correlation heatmap    |
| 🧪 Fixed Acidity      | Distribution, statistics & quality impact       |
| ☢️ Acidity Hub        | Multi-feature acidity analysis & scatter matrix |
| ⚠️ Sulfur & Chemicals | SO₂, density, chlorides & sulphates analysis    |
| 🤖 Quality Prediction | ML-based wine quality prediction                |

---

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Visualization:** Plotly
* **Processing:** Pandas & NumPy
* **Machine Learning:** Scikit-learn
* **Styling:** Custom CSS
